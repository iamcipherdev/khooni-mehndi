# Khooni Mehndi — A Desi Murder Mystery 🔍

**Mehndi ki raat, qatl ka raaz.**

A free, single-file murder mystery game set at a Lahore mehndi night. The groom is found dead — 5 suspects, 16 evidence files, and only one accusation.

## Kaise khelein
1. **Parho** — evidence folders kholo, har file examine karo
2. **Poochho** — 5 mulziman se 15 sawal karo
3. **Pakro** — jhootay daway ko saboot se challenge karo (+100 pts per lie)
4. **Ilzaam** — qatil + tareeqa + motive pick karo, rank pao (Chowkidar se SSP tak)

## Khaas baatein (why it's better)
- **Contradiction-spotter mechanic** — daway ko saboot se challenge karo (dono reference games me ye tha hi nahi)
- **Built-in evidence board** — pinned saboot + pakray jhoot ek jagah (Cold Case Online ka sab se bara gap)
- **Scoring + ranks** — desi police ranks, shareable rank card (viral hook)
- **Retry allowed** — dobara khelo (dono references me ek hi mauqa tha)
- **Hints system** — atak jao to madad (-25 pts)
- **Mobile-first, offline, single HTML file** — no sign-up, no backend
